# projeto-motor-de-busca-textual
AgroSearch é um protótipo de motor de busca textual desenvolvido em Python com Streamlit, aplicando técnicas de Recuperação de Informação e Processamento de Linguagem Natural. O sistema realiza pré-processamento de documentos, construção de índice invertido, cálculo manual de TF-IDF e ranqueamento por relevância a partir de consultas do usuário.
